# 风格系统与路由参考

风格选择优先级：用户明确媒介 > 用户明确时代/材质 > 参考图可见媒介 > 常用题材联想。先确定主媒介，再定子风格。

## 1. 现代真人摄影

适用：现代女性肖像、网红写真、韩系清透、轻奢性感、御姐、商业美容大片。

核心词：真实成年人物、自然皮肤纹理、发丝、妆容光泽、服装剪裁、镜头距离、景深、柔光、商业摄影。

写作重点：脸型与年龄感、妆容强度、肩颈和身体比例、服装质感、镜头互动、背景简洁度。

子风格：

- 韩系清透：非圆脸、薄透底妆、粉棕眼妆、细腻高光、柔和唇色、干净背景。
- 泪光/微醺妆：大面积眼下粉橘或粉棕腮红、眼头细闪、湿润高光唇、琥珀或自然虹膜、无重烟熏。
- 网红甜美：蓬松发型、轻亮妆面、柔和前景、亲近镜头、甜而不幼态。
- 性感御姐：明确成年、成熟眼神、肩颈和锁骨线条、修身剪裁、身体曲线和姿态控制；性感通过造型和镜头表达。

专属负向：圆脸如果用户要求窄脸、过度磨皮、塑料脸、夸张医美感、粗重欧美妆、影楼硬光、廉价背景、手部错误、文字、水印。

## 2. 古装真人电影

适用：宋代贵妃、明制贵女、唐风人物、宫廷、古装剧照、真人武侠、古典水岸。

核心词：明确时代、真实戏服、发髻结构、玉石金属、织物厚度、自然光或实景光、电影剧照、真实人体。

写作重点：朝代一致性、身份等级、发式依据、服装内外层、配色等级、动作功能、实景空间。

子风格：

- 宋代宫廷：克制、雅正、低饱和、轻薄褙子或褙服层次、简洁但精致的首饰、室内自然光或庭院光。
- 明制贵女：立领、袄裙、马面裙、织金和端正发髻，注意形制清楚，避免把唐宋头饰混入。
- 清冷水岸：月白、灰蓝、白色、淡青，侧身回眸，湖岸/芦苇/远山，轻戏曲转译淡妆。
- 真人武侠：窄袖、腰封、护腕、靴子、武器携带方式、动作前后因果和可活动性。

专属负向：现代服装、朝代混搭、廉价塑料头冠、戏服没有层次、影楼硬光、游戏 CG、动漫脸、过量仙侠粒子、无关建筑、文字和水印。

## 3. 港风胶片与复古电影

适用：90 年代港风、复古女星、港片女主、霓虹街景、室内钨丝灯、胶片肖像。

核心词：明艳但克制的唇色、浓密黑发、英气眉眼、丝绒/缎面、霓虹反光、湿地、50mm 或 35mm、适度颗粒。

光色：暖肤色、红绿或蓝红霓虹、黑位略抬高、柔和高光、低到中等饱和度。

专属负向：现代奶油网红滤镜、仙侠头冠、古装纹样、过度锐化、数码塑料感、过强磨皮、动漫化。

## 4. 暗黑哥特与复古时装摄影

适用：维多利亚哥特、烛光肖像、蕾丝头巾、黑白复古、暗黑浪漫。

核心词：明确成年、黑白服装、蕾丝、珍珠、蜡烛、纯黑背景、低调暗光、暖烛光与冷补光、85mm 超浅景深。

视觉重点：眼睛精准对焦，烛火作为实际光源，蕾丝与黑背景形成轮廓，局部暖光照亮脸颊和手部。

专属负向：宗教仪式场景如果用户未要求、现代家具、白天阳光、甜美网红笑容、浓烈赛博光、游戏 CG、蜡烛火焰过曝。

### 4A. 卧室镜面自拍束腰比例写真

适用触发词：落地镜自拍、卧室自拍、束腰、corset、沙漏身材、网红性感写真、手机挡脸、真实房间。

这是现代真人摄影的独立子风格，不使用古装、哥特宗教符号或电影棚拍语言。核心是“镜面空间 + 身材比例 + 私人卧室 + 手机自动曝光”。

- 构图：竖版 3:4 或 4:5，全身镜面取景，28至35mm 手机广角，头部、腰臀、双腿和鞋子完整出现。
- 身体：明确成年，丰满或丰腴沙漏体型，胸腰髋和大腿形成比例反差；用体态和服装结构表达曲线，不默认纤瘦模特比例。
- 服装：束腰要写高度、鱼骨、缝线、排扣、硬挺度和收腰位置，避免退化成普通腰带；丝袜、热裤和高跟鞋要写透光、反光、长度与鞋型。
- 环境：床铺、格纹床单、窗帘、衣架、衣柜、木地板和生活杂物组成真实私人空间，避免酒店或极简样板间。
- 光线：窗户强日光、手机自动曝光、局部过曝、地面投影和有限动态范围；不要自动套用商业柔光和电影调色。
- 负向重点：纤瘦、平胸、直筒腰、窄髋、普通腰带、长裤、厚黑丝袜、网袜、靴子、坐姿、翘腿、棚拍背景、塑料皮肤、身体畸变。

### 4B. 荒漠哥特圣女 / 废土修女真人肖像

适用触发词：荒漠哥特、废土修女、哥特圣女、沙漠遗迹、黑色蕾丝长裙、十字架链饰、维多利亚荒漠幻想。

它与 4A 的卧室自拍、室内烛光哥特和纯历史维多利亚服饰分开处理。核心是“暗黑服饰人物 + 明亮荒漠 + 失落遗迹 + 电影叙事感”。

- 人物：明确成年女性，冷淡、疏离、神秘或疲惫，侧脸看向远方，具有旅者、流亡者或祭司的角色叙事。
- 服装：黑色泡泡袖或蓬袖长裙、高领象牙白蕾丝胸襟、白色蕾丝袖口、黑色束腰，多层银色链条、珍珠链和十字架吊饰。
- 发型：深棕黑色低位盘发或蓬松发髻，脸侧碎发，象牙白蕾丝发饰；头饰与服装形成黑白识别对比。
- 场景：沙丘、荒漠平原、断裂石柱、失落遗迹、远处尖塔或天然岩壁；背景可以柔化，但需要保留环境尺度。
- 色彩：人物使用黑、象牙白、银灰，背景使用沙金、暖棕和灰蓝天空，暗红唇色作为小面积锚点。
- 光线：强烈荒漠日光、暖色反射光、轻微逆光轮廓和柔和面部补光；可以有动作模糊，但脸部和服装结构要稳定。
- 负向重点：纯室内哥特烛光、现代城市、普通修女制服、科幻盔甲、过量宗教建筑、暗黑背景吞没人物、游戏 CG、廉价 Cosplay、过量烟雾和粒子。

## 5. 现代古风插画

适用：新中式插画、现代古风、古风时尚海报、社交媒体国风人物。

核心词：清晰线稿、平涂与渐变、装饰性构图、现代剪裁与古典符号、纸张或印刷肌理、图形化背景。

写作重点：轮廓设计、颜色块、图案布局、服装造型、姿态剪影、留白和海报层次。现代元素必须明确，例如耳机、手机、现代妆发、街头服饰或都市场景。

专属负向：真人摄影、真实毛孔、镜头景深、3D 渲染、西式卡通、游戏立绘、杂乱光效、过度照片感。

## 6. 东方工笔与古典绘画

适用：工笔仕女、宋画气质、古典花鸟人物、绢本人物画、国画古典美人。

核心词：工整线描、细笔勾勒、淡设色或重彩设色、绢本肌理、矿物颜料、留白、散点透视、古典器物。

写作重点：线条粗细、衣纹、面部程式化程度、花鸟器物、题材寓意、画面留白和色彩层级。

专属负向：摄影感、镜头虚化、真实毛孔、商业棚拍、塑料材质、动漫大眼、3D、霓虹滤镜、英文文字。

## 7. 东方神话与玄幻概念艺术

适用：山海经神女、月宫仙姬、海神、神殿、异兽、神话角色设计。

先选媒介：

- 写实电影概念图：真实人体、真实衣料、实体光源、电影构图、实拍质感。
- 数字绘画概念图：绘画笔触、概念色块、环境尺度、设计感和超现实构图。

核心原则：神性来源要具体，核心视觉元素最多三个。例：月神 = 满月光环 + 银白羽饰 + 月白服装；山海经神女 = 异兽纹样 + 山海环境 + 古代祭祀符号。

专属负向：所有神话元素平均堆叠、过量粒子、异兽遮挡人物、光源互相冲突、廉价 Cosplay、游戏 CG 感如果用户要真人、文字和水印。

## 8. 武侠与动作角色

适用：女剑客、镖师、刺客、门派人物、宫门对峙、飞身出剑。

核心词：身份阵营、起始位置、动作目标、武器方向、服装活动性、重心、空间层级、动作瞬间。

写作公式：`角色身份 + 初始位置 + 阵营关系 + 动作目标 + 武器轨迹 + 对手/道具位置 + 服装与镜头`。

动作图优先保证动作读得懂，减少无关花瓣、雾气、复杂头饰和多把武器。

专属负向：静态摆拍、剑刃方向混乱、手臂多余、武器穿模、衣袖遮住动作、人物阵营关系不清、动漫化，除非用户明确要插画。

## 9. 赛博东方与科幻角色

适用：赛博东方、未来女武者、数字神女、机械义体、霓虹街头、科幻设定图。

核心词：机械分区、发光界面、科技织物、金属反射、湿地、霓虹、体积雾、未来城市尺度。

先写材质和结构，再写光效。避免把“东方”只写成随意的红灯笼或龙纹；可以通过建筑、文字系统、服装轮廓、纹样和器物表达。

专属负向：古典宫廷头冠如果用户未指定、普通现代街拍、所有部件都发光、低细节金属、光源混乱、过度紫色渐变。

## 10. 二维动画、漫画与游戏立绘

适用：角色立绘、动漫角色、漫画封面、卡牌、游戏人物设定。

先选语言：日系动画、厚涂概念、平涂漫画、国风动画、欧美漫画等。不要同时写“真人摄影皮肤”和“二维线稿”，除非明确混合媒介。

写作重点：轮廓识别、发型剪影、服装符号、色块、姿态、表情、武器和角色标志物。

专属负向：照片感、错误手部、服装细节堆满导致轮廓不清、同质化脸、背景抢主体、无关文字。

## 11. 三维角色与影视概念设计

适用：三维角色、影视前期概念、游戏角色开发、模型展示。

写作重点：模型比例、材质分区、可制作结构、关节活动、服装层级、转面、灰模/材质球/最终渲染的交付类型。

如果是角色设定板，优先使用正面、侧面、背面统一灯光和中性背景；如果是最终渲染，可加入环境光与叙事场景。

## 12. 历史人物与时代服饰

适用：历史人物、时代肖像、服饰考据、古代贵族、民国人物。

写作重点：时代、地区、身份等级、服装形制、发式、妆容、材质和社会语境。用户只说“古风”时不要自称真实历史考据，可写“架空东方古典”。

专属负向：时代混杂、身份等级不匹配、现代配饰、无法穿着的结构、随意拼接传统元素。
