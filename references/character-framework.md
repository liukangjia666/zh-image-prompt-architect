# 角色框架与统一身份

## 角色卡字段

按任务选择字段，不必每次全部写满：

1. 角色名/称号
2. 明确年龄与年龄感
3. 性别表达与身体类型
4. 时代、地区、身份、职业、阵营
5. 性格关键词和当前情绪
6. 脸型、五官、肤色、皮肤纹理
7. 妆容和妆容强度
8. 发型、发色、发丝和头饰
9. 身高、体型、比例和姿态习惯
10. 服装内外层、鞋履和配饰
11. 武器、道具、宠物或异兽
12. 标志性视觉锚点
13. 场景、光线、主色和构图
14. 禁止改变的身份条件

## 身份锚点

一个角色至少设置三项跨图固定锚点：

- 脸部锚点：脸型、眉眼或鼻唇比例中的一至两项。
- 发型锚点：发色、长度、分缝、发尾或固定发饰。
- 服装锚点：主色、轮廓、固定纹样或固定配饰。
- 道具锚点：武器、玉令、花篮、眼镜、手杖等。
- 气质锚点：安静疏离、锋利克制、甜美亲近等表演状态。

延展系列时，至少保留三项锚点，只替换场景、姿态、光线或局部服装。变体之间不要同时更换脸型、发型、主色和时代。

## 面部写法

推荐顺序：

`脸型和比例 → 眉眼 → 鼻梁和鼻尖 → 唇形和唇色 → 肤质 → 妆容 → 表情、视线和成熟度`

避免互相冲突的写法，例如“脸型窄长”与“大圆脸”同时出现，“浓烈烟熏”与“几乎无妆”同时出现，“幼态少女”与“成熟御姐”同时作为主气质。

“自然真实”不等于删除所有修饰。可以写“皮肤干净通透，保留毛孔、细小纹理、鼻尖高光和面部绒毛”，同时保留适度的妆容和光线控制。

## 妆容分级

- 裸感淡妆：薄底妆、自然眉、贴根眼线、轻腮红、柔润唇。
- 韩系清透：浅粉棕眼影、卧蚕提亮、细长睫毛、低饱和唇、非圆脸轮廓。
- 泪光/微醺：眼下大面积粉橘或粉棕腮红、眼头细闪、湿润唇釉、柔和无辜感。
- 古典东方妆：平缓细眉、自然眼线、低饱和朱红/豆沙唇、柔和面部高光。
- 轻戏曲转译：细长眉、修长眼型、克制红棕下眼睑、精确唇峰；保持真人妆感。
- 网红甜美：明亮眼神、轻亮卧蚕、蓬松睫毛、柔光唇、面部高光；避免幼儿化。
- 性感御姐：更清晰的眼尾、成熟唇色、立体但克制的修容、肩颈和眼神成为视觉重点。
- 哥特妆：冷白肤色、细黑眼线、冷粉/灰棕眼影、暗红或豆沙唇、低调高光。

## 发型与头饰结构

头饰至少按五个维度写：

- 固定位置：发髻顶部、额前、左右鬓角、耳侧、后脑或肩部。
- 主体结构：冠、簪、花钿、发带、蕾丝头巾、金属框架或机械模块。
- 材质：玉石、珍珠、羽毛、金银、蕾丝、丝绸、玻璃、金属。
- 层级和数量：主件、辅件、少量点缀，避免每件都同等巨大。
- 受光反应：半透明、冷硬反光、柔和珠光、金属高光、织物吸光。

## 服装材质句式

用“材质 + 结构 + 可见特性”写，而不是只写面料名称：

- 真丝：表面有柔和连续高光，褶皱随重力自然下垂。
- 锦缎：织物较厚，图案嵌入表面，折叠处出现方向变化的反光。
- 刺绣：线迹有细微凸起，金线与底布的反光不同，纹样边界清楚。
- 轻纱/欧根纱：半透明，多层重叠后颜色加深，边缘受光清晰。
- 皮革：表面有细密纹理、稳定反射和结构支撑，不像塑料。
- 玉石：半透明或不透明，内部有自然色差、柔和透光和局部高光。
- 金属：边缘高光明确，平面和弧面反射不同，表面有真实磨损或细微纹理。
- 羽毛：单根羽枝可见，边缘柔软，受逆光后呈半透明轮廓。

## 姿态与手部

姿态要同时写“方向、重心、肩颈、手部和视线”：

- 方向：正面、三分之四、侧面、背身回眸、向左/向右。
- 重心：双脚平稳、单腿承重、行走中、跃起、俯身、倚靠。
- 肩颈：放松、舒展、前倾、警觉、带有动作惯性。
- 手部：哪只手、在画面哪侧、手掌朝向、手指状态、是否接触道具。
- 视线：镜头、镜头左侧、远处目标、对手、道具或地面。

避免只写“优雅摆姿势”“自然拿剑”。对武器要说明握法、剑尖方向、手臂关系和运动目标；对袖中物件要写“袖口或手腕处露出部分线索”，使剧情信息可见但不破坏动作。

## 设定图一致性

三视图、四视图和角色表情图必须重复：同一张脸、同一发型、同一服装、同一主色、同一比例、同一配饰。变化只发生在视角、表情或动作。设定图不使用强烈景深和大面积前景遮挡，以便看清服装结构。
