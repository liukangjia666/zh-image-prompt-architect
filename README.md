# 中文角色图像提示词架构师

一个面向静态角色图像的 Codex Skill，用中文生成、拆解、优化和延展图像提示词。它先判断媒介与主风格，再组织角色身份、妆发、服装、姿态、道具、环境、构图、光线和负向约束，避免把所有题材写成同一种视觉语言。

## 能做什么

- 根据一句角色设定生成可直接使用的完整中文提示词。
- 拆解参考图或已有提示词，提炼可复用的写法。
- 优化现有提示词，补足画面关系、材质和镜头信息。
- 设计角色卡、全身角色图、三视图、四视图和系列变体。
- 保持同一角色跨图的脸部、发型、服装和道具识别点。
- 根据用户反馈定点修订，例如“不要圆脸”“妆太重”“太像 CG”“身材比例不对”。

此 Skill 只处理静态图像提示词，不编写视频分镜、镜头运动或音效脚本。

## 使用方式

把仓库克隆到 Codex 的 skills 目录，以便 Codex 自动发现它：

```bash
git clone https://github.com/liukangjia666/zh-image-prompt-architect.git ~/.codex/skills/zh-image-prompt-architect
```

在 Codex 中可以直接描述需求，也可以显式调用 `$zh-image-prompt-architect`。例如：

```text
用 $zh-image-prompt-architect 写一个明制国风美男的真人电影角色提示词，竖构图，全身，强调服装形制。
```

```text
用 $zh-image-prompt-architect 分析这张参考图的妆容、服装、镜头和光线，提炼可复用的写法，先不要生成新提示词。
```

```text
用 $zh-image-prompt-architect 把这个角色扩展成正面、侧面、背面和面部特写四视图，保持同一张脸、同一发型和同一套服装。
```

## 写作原则

1. 先识别用户要的是完整提示词、参考图分析、优化、角色卡还是多视图。
2. 先确定媒介，再确定主风格。只有明确要求融合时才混合风格。
3. 保留用户指定的年龄、身份、体型、服装、姿态、道具、场景和禁止项。
4. 用可见的结构与材质描述取代空泛形容词。
5. 摄影、插画、工笔和三维设定分别使用各自的构图与质感语言。
6. 负向提示词只针对当前风格与任务，不堆通用词表。

## 说明

本仓库不包含图像生成模型或图片素材。它提供提示词设计方法，实际出图效果仍取决于所使用的图像生成工具、参考图和参数。
